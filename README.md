# Мои кредиты

Файлы для публикации личного трекера кредитов через GitHub Pages.

Загрузите содержимое архива в корень репозитория `mini-credit-tracker`, сохраняя папку `icons`. В `index.html` подключён отдельный `manifest.json` с уникальным идентификатором `/mini-credit-tracker/`, чтобы Chrome мог отличать трекер от календаря.

Данные приложения хранятся в localStorage этого браузера и устройства.
