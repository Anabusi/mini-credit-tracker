# Мои кредиты 💳

Минималистичный личный трекер кредитов и рассрочек. Работает в браузере без сервера и хранит данные локально в `localStorage` этого браузера.

## Возможности

- Сводка: общий остаток долга, платежи текущего месяца и ближайший платёж.
- Карточки кредитов с остатком, ближайшей датой и количеством оплаченных/оставшихся платежей.
- Добавление и редактирование кредитов.
- Возможность указать количество платежей, уже оплаченных до добавления кредита.
- Кнопка «Оплачено» уменьшает остаток, обновляет прогресс и сдвигает дату следующего платежа.
- Адаптивный интерфейс для телефона и компьютера.

## Публикация через GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите `index.html` и `README.md` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе сборки выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, затем сохраните настройки.
6. Дождитесь публикации и откройте адрес Pages, который покажет GitHub.

## Важные замечания

- Данные сохраняются только в локальном хранилище браузера на конкретном устройстве. Они не синхронизируются автоматически между устройствами и могут быть потеряны при очистке данных браузера.
- Это органайзер, а не банковская система: суммы и число платежей — ориентировочные. Для нестандартных графиков или отличающегося последнего платежа проверяйте значения вручную.
- Перед внесением реальных данных удалите демонстрационные карточки из приложения.
